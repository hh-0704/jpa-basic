# 자바 ORM 표준 JPA 프로그래밍 - 기본편

인프런 [김영한의 자바 ORM 표준 JPA 프로그래밍 - 기본편](https://www.inflearn.com/course/ORM-JPA-Basic) 강의를 수강하며 따라 작성한 학습용 코드 저장소입니다.

스프링 없이 순수 JPA(Hibernate)만으로 엔티티 매핑, 연관관계, 영속성 컨텍스트, 프록시, JPQL을 직접 다뤄보며 JPA의 내부 동작 원리를 이해하는 것을 목표로 합니다.

## 기술 스택

| 구분 | 버전 |
| --- | --- |
| Java | 17 |
| JPA 구현체 | Hibernate 6.4.2.Final |
| Database | H2 2.2.224 |
| Build | Maven |

```
├── (실전 예제)       # 쇼핑몰 도메인에 챕터별 내용을 적용하는 실전 예제 1~6 (예정)
└── (JPQL)           # 객체지향 쿼리 언어 실습 (예정)
```

## 핵심 키워드

- **영속성 컨텍스트**: 1차 캐시, 동일성 보장, 쓰기 지연, 변경 감지(Dirty Checking), 플러시
- **엔티티 매핑**: `@Entity`, `@Table`, `@Column`, `@Id`, 기본 키 생성 전략, 스키마 자동 생성
- **연관관계 매핑**: 단방향·양방향 연관관계, 연관관계의 주인, `mappedBy`
- **다양한 연관관계**: 다대일, 일대다, 일대일, 다대다와 연결 엔티티
- **고급 매핑**: 상속관계 매핑(조인, 단일 테이블, 구현 클래스마다 테이블), `@MappedSuperclass`
- **프록시와 연관관계 관리**: 프록시, 즉시 로딩과 지연 로딩, 영속성 전이(CASCADE), 고아 객체
- **값 타입**: 기본값 타입, 임베디드 타입, 값 타입 컬렉션, 불변 객체
- **JPQL**: 기본 문법, 프로젝션, 페이징, 조인, 서브쿼리, 페치 조인, 벌크 연산, Named 쿼리
